# Number Guessing Game 🎯

## About Project
A Java-based console game where the computer generates a random number and the player tries to guess it within limited attempts.

## Features
- Random number generation (1-100)
- Too High / Too Low hints
- Maximum 7 attempts
- Attempt counter
- Play Again option
- Score tracking
- Input validation

## Technologies Used
- Java
- OOP Concepts
- Random Class
- Scanner Class
- Loops
- Conditional Statements

## How to Run
1. Download the project
2. Open NumberGuessingGame.java
3. Compile and run the program
